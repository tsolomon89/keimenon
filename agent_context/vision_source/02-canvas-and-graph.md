# Theme 02: Canvas and Graph

## Canonical statements

1. Core surface is a memory board/canvas linking sources and conversations.
2. Graph experience is multi-scale and should support galactic abstraction at high level with progressive detail as users zoom.
3. View controls must support multiple graph views (2D/3D/higher-dimensional mode concepts) and camera actions.
4. Navigator selection (groups/folders) and canvas selection (nodes/edges) are bidirectionally linked with inspector detail.
5. Interaction supports multi-select semantics (standard ctrl/cmd and shift workflows).
6. Node naming in UI should prioritize human-readable labels over opaque IDs.

## De-duplication resolution

- Repeated graph visualization descriptions were consolidated into one multi-scale interaction contract.
