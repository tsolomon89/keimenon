# Theme 04: Tiers and Agents

## Canonical statements
1. Tier framing includes Free, Pro, and Business, with admin/debug used as development super-profile.
2. Free is baseline graph experience with limits and no autonomous research automation.
3. Pro adds higher automation/agent capability and verification/research behavior.
4. Business extends Pro with organization/workflow and multi-user/account-oriented behavior.
5. Agent behavior should be capability-gated by tier and entitlement.
6. Objective/archetype intermediary nodes are expected between subjective sources and validated outputs.

## De-duplication resolution
- Multiple tier variants were normalized into the stable Free/Pro/Business progression.
- Agent node expectations were merged with objective/archetype descriptions.
