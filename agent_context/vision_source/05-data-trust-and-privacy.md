# Theme 05: Data Trust and Privacy

## Canonical statements

1. Imported source payloads should be preserved as "real" data and not rewritten during grouping/sorting.
2. Duplicate logic should identify and stage review decisions rather than silently rewriting source truth.
3. Provenance and objective verification chains are core to trusted outputs.
4. Local-first handling is mandatory for personal content in Free/Pro framing.
5. BYOK and minimal platform custody of personal data are explicit expectations.

## De-duplication resolution

- Statements about "do not modify content with AI" are treated as stronger than convenience merge language.
- Privacy posture is interpreted as local-first default with explicit, auditable exceptions only.
