## Critical Vulnerabilities

### 1. happy-dom (VM Context Escape → RCE)

**CVEs**:

- GHSA-96g7-g7g9-jxw8 (Server-side code execution via `<script>` tag)
- GHSA-37j7-fg3j-429f (VM Context Escape → RCE)

**Affected Version**: <=19.0.2
**Fix Available**: Upgrade to 20.0.11 (breaking change)
**Impact**: Development/testing only (not production)
**Command**: `npm install happy-dom@20.0.11 --save-dev`

**Risk Assessment**: LOW (dev dependency, not exposed in production)

### 2. next (Multiple Security Issues)

**CVEs**:

- GHSA-gp8f-8m3g-qvj9 (Cache Poisoning)
- GHSA-g77x-44xx-532m (DoS in image optimization)
- GHSA-7m27-7ghc-44w9 (DoS with Server Actions)
- GHSA-3h52-269p-cp9r (Information exposure in dev server)
- GHSA-g5qg-72qw-gw5v (Cache Key Confusion)
- GHSA-7gfc-8cq8-jh5f (Authorization bypass)
- GHSA-4342-x723-ch2f (SSRF via middleware redirect)
- GHSA-xv57-4mr9-wg8v (Content Injection in image optimization)
- GHSA-qpjv-v59x-3qc4 (Race Condition → Cache Poisoning)
- GHSA-f82v-jwr5-mffw (Authorization Bypass in Middleware)

**Affected Version**: 0.9.9 - 14.2.31
**Fix Available**: Upgrade to 14.2.33 (outside stated dependency range)

**Command**: `npm install next@14.2.33`

**Risk Assessment**: MEDIUM-HIGH (production dependency, multiple attack vectors)

## High Vulnerabilities

### 3. glob (Command Injection)

**CVE**: GHSA-5j98-mcp5-4vw2
**Details**: CLI command injection via `-c/--cmd` executes matches with `shell:true`
**Affected Version**: 10.2.0 - 10.4.5
**Fix Available**: Upgrade (breaking change for eslint-config-next)
**Impact**: Development/testing only
**Command**: `npm audit fix --force` (will install eslint-config-next@16.0.5)

**Risk Assessment**: LOW (dev dependency, not using glob CLI)

## Moderate Vulnerabilities

### 4. @sentry/node & @sentry/node-core (Information Disclosure)

**CVE**: GHSA-6465-jgvq-jhgp
**Details**: Sensitive headers leaked when `sendDefaultPii` is set to `true`
**Affected Version**: @sentry/node 9.34.0-alpha.1 || 9.36.0-alpha.1 - 9.36.0-alpha.2 || 10.11.0 - 10.26.0
**Fix Available**: `npm audit fix` (non-breaking)
**Impact**: Production (error tracking)

**Risk Assessment**: LOW (only if `sendDefaultPii: true` is configured)

### 5. esbuild (Development Server Security)

**CVE**: GHSA-67mh-4wv8-2f99
**Details**: Dev server allows any website to send requests and read responses
**Affected Version**: <=0.24.2
**Fix Available**: Upgrade vitest (breaking change)
**Impact**: Development only
**Command**: `npm audit fix --force` (will install vitest@4.0.14)

**Risk Assessment**: LOW (dev dependency, dev server not exposed)

### 6. js-yaml (Prototype Pollution)

**CVE**: GHSA-mh29-5h37-fv8m (listed twice)
**Details**: Prototype pollution in merge operator (`<<`)
**Affected Version**: <3.14.2 || >=4.0.0 <4.1.1
**Fix Available**: `npm audit fix` (non-breaking)
**Impact**: Development/testing only

**Risk Assessment**: LOW (unlikely to process untrusted YAML)
